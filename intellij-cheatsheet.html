Plugins con valor real

Curados para microservicios y sistemas distribuidos: Spring, Redis, testing de carga, profiling y observabilidad. La regla: cada plugin que instalés tiene que ganarse su lugar. Tool fatigue es real — agregá de a uno y medí si te hace más rápido.

03

Free vs Ultimate (modelo 2025.3)

⚠ Lo que cambió — léelo primero

Desde IntelliJ IDEA 2025.3 (diciembre 2025) ya no existen instaladores separados Community y Ultimate. Hay un solo producto: "IntelliJ IDEA". Todo lo que era Community sigue gratis (incluso uso comercial), y Ultimate pasó a ser una capa de suscripción que desbloqueás dentro del mismo IDE, con trial de 30 días. Si tu suscripción expira, no te bloquean: el IDE simplemente vuelve al set de features gratis. La pregunta ya no es "cuál instalo", sino "qué me desbloquea la suscripción".

Free tier
// lo que antes era Community + extras nuevos
  • Java, Kotlin, Groovy, Scala con refactors completos
  • Maven, Gradle, Ant — soporte nativo de primera
  • Git / GitHub, debugger y profiler (async + JFR)
  • JUnit / TestNG y cobertura básica
  • Decompiler, análisis de código, inspecciones
  • Nuevo gratis: highlighting Spring/Jakarta EE, SQL básico y wizard de Spring Boot
  • Visor de base de datos de solo lectura
Ultimate (suscripción)
// la capa que de verdad te sirve en banca + microservicios
  • Soporte Spring / Spring Boot completo — beans, endpoints, diagramas, config
  • Database Tools & SQL (DataGrip): Postgres, Oracle, Redis, Mongo
  • HTTP Client (.http versionables)
  • Docker · Kubernetes · Remote Dev
  • Jakarta EE, MicroProfile, Quarkus, Micronaut
  • Application Servers (Tomcat, WildFly…) y deployment
  • AI Assistant y profiling avanzado
  • JavaScript/TypeScript y frameworks web
Cómo exprimir Ultimate en tu día a día
① Run Dashboard / Services

Levantá y monitoreá varios microservicios a la vez en una sola ventana, con su estado y logs agrupados. Usá Compound Run Configurations para arrancar todo el stack local de un golpe.

② Endpoints tool window

Lista todos los endpoints REST del proyecto y de servicios consumidos. Saltás de la definición del controller al sitio donde se llama, ideal para integraciones tipo TSYS/Monibyte.

③ HTTP Client en el repo

Guardá los requests .http con environments por ambiente (dev/qa/prod). Se versionan, se revisan en PR y reemplazan colecciones de Postman sueltas.

④ Actuator + Spring beans

Inspeccioná health, metrics y el grafo de beans en vivo desde el dashboard. Diagrama de dependencias para entender un servicio nuevo en minutos.

⑤ Database tools unificados

Una sola herramienta para todas las DBs del banco: consola SQL con autocompletado, comparar esquemas entre ambientes y exportar resultados.

⑥ Profiler para incidentes

Adjuntá el profiler a un servicio corriendo y sacá flame graphs de CPU/memoria. Lo que convierte "se satura la memoria" en "esta línea retiene los objetos".

04

Tips, tricks & sistema

Los trucos que separan a quien "usa IntelliJ" de quien lo tiene en automático, más un método concreto para llegar ahí sin frustrarte.

⌥

Scratch files

Probá código o pegá un JSON sin ensuciar el proyecto con Ctrl+Alt+Shift+Insert. Soportan ejecución, formato y resaltado por lenguaje.

↺

Local History

Click derecho → Local History. Recuperás cualquier versión de un archivo aunque nunca hayas hecho commit. Te salva de un Ctrl+Z fatal.

⚑

Bookmarks con mnemónico

Ctrl+F11 marca una línea con una letra/número. Volvés a ella con Ctrl+<número> desde cualquier archivo.

⊞

Actions on Save

Settings → Tools → Actions on Save: reformatear y organizar imports automáticamente al guardar. Adiós a hacerlo a mano.

⌕

Structural Search

Buscá por estructura de código, no por texto: "todos los catch vacíos" o "métodos sin @Override". Find Action → SSR.

⧉

Code With Me

Pair programming remoto nativo (Ultimate). Compartís la sesión del IDE con Greivin sin screen-share laggy.

⊟

Distraction-free / Zen

View → Appearance → Enter Zen Mode. Para foco profundo. Presentation Mode agranda todo: perfecto para tus workshops.

⟳

Settings Sync

Sincroniza keymap, plugins y temas vía tu cuenta JetBrains. Mantené idénticos tu PC del trabajo y la Mac… respetando la separación corp/personal.

↹

Recent Locations

Ctrl+Shift+E: no solo archivos recientes, sino los lugares exactos donde estuviste, con preview. Más preciso que el historial normal.

El loop sin mouse

Una sesión de desarrollo entera puede correr sin tocar el trackpad. El patrón mental es siempre el mismo: navegar → editar → refactorizar → correr → versionar.

Navegar

Llegá al código con ⇧⇧ y Ctrl+B. Nunca busques scrolleando.

Editar

Live templates + postfix + Alt+Enter para todo lo demás.

Refactor

Extraé método/variable en caliente. Renombrá con ⇧F6.

Correr

Debug con breakpoint condicional y Alt+F8 para evaluar.

Versionar

Ctrl+K commit → revisás el diff → Ctrl+Shift+K push.

MÉTODO Adopción 5-por-semana

  1. Instalá Key Promoter X. Deja que te muestre qué acciones de mouse tienen atajo.
  2. Elegí 5 hotkeys por semana de esta hoja (empezá por la tarjeta de Navegación) y pegalos en un sticky en el monitor.
  3. Prohibite el mouse para esas 5 acciones esa semana, aunque sea más lento al inicio.
  4. La siguiente semana sumá 5 nuevos sin abandonar los anteriores. En ~6 semanas tenés los 30 core en automático.
  5. Medí: cuando Key Promoter X deje de molestarte, ya están internalizados.

SETUP Higiene del IDE

  1. Activá Actions on Save (reformat + optimize imports) una sola vez y olvidate.
  2. Definí Compound Run Configs con tus microservicios locales para arrancar el stack de un click.
  3. Versioná tus .http en cada repo: tu documentación viva de la API.
  4. Creá live templates propios para el boilerplate del banco (logging, manejo de errores, headers).
  5. Settings Sync solo en lo personal; mantené el perfil corp aparte para respetar la política.
